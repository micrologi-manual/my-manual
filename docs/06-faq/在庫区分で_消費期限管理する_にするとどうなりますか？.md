# 在庫区分で【消費期限管理する】にするとどうなりますか？

---

import './style.css';

> **_Q:_**
>
> **_在庫区分で【消費期限管理する】にするとどうなりますか？_**
>
> **_A:_**
>
> > **_①在庫に消費期限が入っていないと引き当たらなくなる。_**
>
> **_在庫管理＞在庫情報（商品別）画面で確認できる該当の品番に消費期限が入力されていない場合は引当（在庫減算）が出来ません。_**
>
> > **_②消費期限が早い在庫から引き当たるようになる。_**
>
> **_在庫管理＞在庫情報（商品別）画面で登録されている在庫の内、一番消費期限の若い物から引当が行われます。_**
>
> > **_③消費期限で引当制限をかけることができる。_**
>
> **_商品管理＞商品マスター一覧の編集画面にて、引当制限を設定することが可能です。（消費期限が引当日より●日以内の場合は引当不可）_**
