# ダッシュボード画面

ダッシュボードでは、当日の出荷予定数や月間出荷数レポートなど、様々な情報が確認できます。


### 保留・確認待ち・未引当

![保留・確認待ち・未引当](https://placehold.co/600x400)

出荷管理画面のステータスが「保留」になっている注文数を確認できます。

| 保留ステータス | 保留ステータス内容 |
| :--- | :--- |
| **保留(入金確認)** | 入金確認が取れない注文を、保留ステータスへ移動したい場合に使用。標準の「銀行振込保留」などの処理ロボットが起動した場合、自動的にこのステータスへ移動します。 |
| **保留(住所不備)** | 住所不備のある注文を、保留ステータスへ移動したい場合に使用。標準の「住所不備(郵便番号不一致)保留」などの処理ロボットが起動した場合、自動的にこのステータスへ移動します。 |
| **保留(備考確認)** | 備考欄に文言がある注文を、保留ステータスへ移動したい場合に使用。標準の「倉庫備考チェック」「店舗備考チェック」などの処理ロボットが起動した場合、自動的にこのステータスへ移動します。 |
| **保留(要確認)** | 上記以外の確認事項がある注文を、保留ステータスへ移動したい場合に使用。標準の「ポスト便で代引き保留」などの処理ロボットが起動した場合、自動的にこのステータスへ移動します。 |
| **保留(後払いデータ)** | 支払方法が後払い(後払い用紙同梱)にも関わらず印字データが登録されていない注文を、保留ステータスへ移動したい場合に使用。標準の「印字データ未取込み保留」などの処理ロボットが起動した場合、自動的にこのステータスへ移動します。 |
| **保留(入荷待ち未引当)** | AiR Logi（弊社WMS）で仮引当を行った際、「未引当」にステータス変更すると、CommerceRobo上でこのステータスに移動します。 |

### 本日の出荷

![本日の出荷](https://placehold.co/600x400)

本日の出荷数・返品数・キャンセル数を確認できます。

<div className="p-4 my-4 border-l-4 border-amber-500 bg-amber-50 dark:bg-amber-950/20 text-amber-900 dark:text-amber-200">
  <p className="font-bold">⚠️ 注意</p>
  <p>ダッシュボードに表示される件数は「出荷予定日」が「当日」の件数です。</p>
  <p className="mt-2 text-sm">
    <strong>例）</strong>2022年12月26日にダッシュボードを閲覧している場合、注文の出荷予定日が2022年12月26日の注文本数が表示されます。<br />
    ※出荷管理画面の各ステータスの件数は出荷予定日当日とイコールではありません。
  </p>
</div>

| ステータス名 | ステータス内容 |
| :--- | :--- |
| **出荷待ち** | AiR Logi（WMS）上で引当（出荷作業開始）前の注文ステータスです。 |
| **出荷準備中** | AiR Logiで帳票(納品書)未印刷・未梱包・未出荷の状態の注文ステータスです。 |
| **出荷作業中** | AiR Logiで帳票(納品書)印刷済・未梱包・未出荷の状態の注文ステータスです。 |
| **出荷検品済** | AiR Logiで梱包済・未出荷の状態の注文ステータスです。 |
| **出荷済み** | AiR Logiで出荷済の状態の注文ステータスです。 |
| **返品** | AiR Logiで返品登録が行われた注文のステータスです。 |
| **キャンセル** | CommerceRobo上でキャンセル処理が行われた注文のステータスです。 |

### 月間出荷数と売上レポート/年間出荷数と売上レポート

![月間出荷数と売上レポート/年間出荷数と売上レポート](https://placehold.co/600x400)

月間の出荷数と年間の出荷数をレポートで確認できます。

- **月間出荷数**: 0時・6時・15時・20時に更新しています。
- **年間出荷数**: 毎日24時に、当日の売上額を計算（ステータス出荷済み注文数 × 各注文の請求金額）し、レポートに反映させます。
