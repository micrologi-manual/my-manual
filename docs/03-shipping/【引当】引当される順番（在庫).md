# 【引当】引き当てされる順番(在庫)

---

<div style={{ border: '1px solid #ccc', padding: '10px', fontSize: '24px', color: '#000000', backgroundColor: '#a9a9a9' }}>
  応用設定を利用されている場合は異なります。
</div>

### 【デフォルト値】  
①消費期限が早い※    
② ロットが若い（ブランク優先）  
③ ロケーションが若い   

◆若い＝記号＞数字＞アルファベット

<span className="red">※消費期限管理する場合、在庫に消費期限が登録されていない（ブランク）と<br />引当てされません。</span>  
 <span className="red">消費期限管理しない場合はブランク優先。</span>
