<h1>在庫情報を確認する</h1>

本ページでは、microLogiで在庫情報を確認する方法について説明します。

-   [**現在存在する在庫情報を確認する**](#h_01G0DXTQG1531NYCD44ETHTAE2)
-   [**過去に存在していた在庫情報を確認する**](#h_01G0DXVQ9P2MZ3JYZDS2D6MRHH)

<div style={{ padding: '10px', color: '#000000', backgroundColor: '#FFFFFF' }}><br />microLogiでは在庫情報を確認するメニューが3つありますが「店舗スタッフ」権限のユーザーアカウントは<br />デフォルトでは「<strong><a href="https://airlogi-help.zendesk.com/hc/ja/articles/4409244982681">在庫情報(商品別)</a></strong>」「<strong><a href="https://airlogi-help.zendesk.com/hc/ja/articles/4409244990233">[在庫情報(ロケ別)]</a></strong>」のサブメニューの閲覧権限はありません。<br />必要な場合は「倉庫管理者」権限のユーザーにて **[アカウント管理＞ユーザー一覧](https://airlogi-help.zendesk.com/hc/ja/articles/4409350592281)**より「**[在庫情報(商品別)](https://airlogi-help.zendesk.com/hc/ja/articles/4409244982681)**」<br />「 **[在庫情報(ロケ別)](https://airlogi-help.zendesk.com/hc/ja/articles/4409244990233)** 」の閲覧権限を付与したいユーザーに権限付与を行ってください。<br /><span className="red">※「在庫情報(商品別)」「在庫情報(ロケ別)」では在庫調整や在庫移動が可能です。<br />閲覧権限を変更する場合は、上記ご留意のうえご判断ください。</span></div>

<h2 id="h_01G0DXTQG1531NYCD44ETHTAE2">現在存在する在庫情報を確認する</h2>

- *

現在存在する在庫は「**[在庫情報](https://airlogi-help.zendesk.com/hc/ja/articles/4409244979865)**」「**[在庫情報(商品別)](https://airlogi-help.zendesk.com/hc/ja/articles/4409244982681)**」「**[在庫情報(ロケ別)](https://airlogi-help.zendesk.com/hc/ja/articles/4409244990233)**」の3つのサブメニューにて確認可能です。

基本的には荷主様は「**[在庫情報](https://airlogi-help.zendesk.com/hc/ja/articles/4409244979865)**」を、  
倉庫ご担当者様は必要に応じて「**[在庫情報(商品別)](https://airlogi-help.zendesk.com/hc/ja/articles/4409244982681)**」「**[在庫情報(ロケ別)](https://airlogi-help.zendesk.com/hc/ja/articles/4409244990233)**」を使い分けくださいませ
